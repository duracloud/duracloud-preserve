# User Resources

Additional resources are available for DuraCloud Preserve users.

## Lyrasis Hosting client resources

Lyrasis-hosted DuraCloud Preserve clients can review the Frequently Asked Questions (FAQs) and other documentation on the [Zendesk Knowledge Base](https://lyrasis.zendesk.com/hc/en-us/categories/46366990083085-DuraCloud-Preserve). The FAQs and other resources are periodically updated.

## Quick video tutorials

Short video tutorials on using various aspects of DuraCloud Preserve, using the three tools supported in this documentation, are available on the [DuraCloud Preserve YouTube channel](https://www.youtube.com/@duracloudpreservevideos). Again, these videos are being added to periodically.

## Feedback?

Are there other resources you wished were available as a DuraCloud Preserve user? Is there anything in this documentation you find confusing or would like clarification around? Email dcp@lyrasis.org and let us know.
